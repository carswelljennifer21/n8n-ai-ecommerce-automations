# AI Customer Support Agent

An AI-powered customer support automation built with n8n.

## What It Does

* Receives customer inquiries
* Uses AI to understand the customer's message
* Generates an appropriate response
* Helps automate repetitive customer support tasks

## Tools Used

* n8n
* AI / LLM
* Workflow Automation
* API Integrations

## Goal

To help businesses respond to customer inquiries faster while reducing repetitive manual work.
